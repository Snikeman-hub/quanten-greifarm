# Quanten-Greifarm Arcade

Ein physikbasiertes Arcade-Greifarmspiel für den Browser mit 3 Quanten-Fähigkeiten, Shop-Upgrades und Web Audio API Soundeffekten.

## Live spielen
- https://greifarm.thetimo.de
- https://greifarm.der-timoo.de

## Features & Spielmechanik
- **3 Quanten-Fähigkeiten:**
  - 🧲 **Magnet-Impuls:** Zieht metallische/schwere Objekte (Gold-Krone, Quanten-Kristall) zur Kralle.
  - 🔬 **Schrumpf-Strahl:** Verkleinert Radius und Gewicht von Objekten unter dem Greifer.
  - ⏱️ **Zeit-Stasis:** Friert schwebende oder wegrutschende Objekte für 5 Sekunden ein.
- **Physik-Simulation:** Gewicht, Reibung, Auftrieb (Helium-Ballon) und Kollisionen.
- **Shop & Upgrades:** Greifkraft, Motor-Geschwindigkeit und Batterie-Regeneration mit Münzen verbessern.
- **Steuerung:** Pfeiltasten / `A` & `D` (Bewegen), `Leertaste` (Greifen), `E` / `Shift` (Kniff auslösen) sowie Touch-Steuerung.
